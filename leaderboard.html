Leaderboard

Every result MemCommit has, as boards you can switch between: public memory benchmarks against other memory systems on one model, the synthetic memory benchmark, eviction policies, and the forgetting curve.

The boards are initial results, and they say so. The public benchmarks (LoCoMo, LongMemEval, ConvoMem) run every system on the same local 8B model, for ingestion, answers, and judging, on small stratified subsets, through the MemEval harness. A board appears when its runs finish. On the synthetic memory benchmark, searching the episodic record answers about 96% of questions from about 20 words, and the oracle rows show the notes pipeline reaching 100% when extraction is perfect. On the forgetting curve, frequency matters more than recency, and a retention curve fitted to it predicts the next session best.
