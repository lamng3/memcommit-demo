A transactional memory layer for agents

MemCommit keeps what agents did and learned as memories in one append-only log, with provenance, tiers, and an offline pass that turns finished sessions into notes and facts. Reasoning over the facts writes memories that go stale with their premises, and eviction weighs a forgetting curve fitted to real conversations against what each memory is.
