What each state means to the agent
Live

It holds. Recall, search and the note index return it, and the agent may act on it.

Stale: outdated

It was right when written, but something it was built on changed: Alice moved, so the trip plan from Lyon no longer holds. Recall and search skip it, so the agent does not act on it. Redo the work, and if it comes out the same, it is restored.

Retracted: wrong

It was never true, like a spoofed session. Skipped the same way; the difference is the reason. What was built on it goes stale.

Archive (a tier, not a state)

Still true, but out of working memory, like cold storage. Search reaches it only when asked to.

Fetching a memory directly by its id still returns it, labelled with its state. Nothing is ever deleted by going stale or being retracted.
